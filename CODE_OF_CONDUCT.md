# Verhaltenskodex / Code of Conduct

Wir verpflichten uns zu einem offenen, freundlichen und respektvollen Umgang
miteinander — unabhängig von Erfahrung, Hintergrund oder Identität.

**Erwünscht:** konstruktive Kritik, Geduld mit Einsteigern, sachliche Diskussion.
**Unerwünscht:** persönliche Angriffe, Diskriminierung, Spam, das Posten
fremder persönlicher Daten (Achtung: Gesundheitsdaten!).

Verstöße bitte an drawn.hunter@proton.me melden. Maintainer dürfen Inhalte
entfernen und bei Wiederholung von der Teilnahme ausschließen.

(Angelehnt an den Contributor Covenant, Version 2.1.)
